##  Задание 1. Артефакты и минимальный объём

###  Цель
Найти комбинацию артефактов с минимальным суммарным объёмом при условии, что общий вес попадает в диапазон `[a, b]`.

###  Алгоритм
1. Считывание параметров задачи из файла `f.txt`: количество артефактов `n`, диапазон весов `[a, b]`, массив весов и объёмов.  
2. Проверка корректности входных данных.  
3. Динамическое программирование:  
   - `dp[w]` хранит минимальный объём для веса `w`.  
   - Обновление: для каждого артефакта проверяется возможность добавить его к текущему весу.  
4. Поиск минимального объёма среди весов в диапазоне `[a, b]`.  
5. Восстановление выбранных артефактов.  
6. Вывод результата.

## Задание 2. Черепашка и максимальная сумма

###  Цель
Найти максимальную сумму чисел при движении «черепашки» от верхнего правого угла до нижнего левого, двигаясь только вниз и влево.

###  Алгоритм
1. Считывание размера матрицы `n` и её элементов из файла `21.txt`.  
2. Проверка корректности входных данных (`n` в диапазоне 1..80, элементы 0..100).  
3. Динамическое программирование:  
   - `dp[i][j]` хранит максимальную сумму до клетки `(i, j)`.  
   - Переход: `dp[i][j] = max(dp[i-1][j], dp[i][j+1]) + board[i][j]`.  
4. Результат — значение в клетке `(n-1, 0)`.  
5. Запись результата в файл `22.txt` и вывод на экран.
